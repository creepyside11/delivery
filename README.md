# Тихая почта — зимние доставки

Браузерная 3D-игра от первого лица о курьере в заснеженном городке. Стилистика вдохновлена предоставленными референсами: синий зимний вечер, деревянные дома, снег и тёплые окна. Это первая игровая версия с процедурной low-poly графикой.

## Запуск

Требуется Node.js 22 или новее. Установка пакетов не нужна: Three.js 0.180.0 поставляется в `vendor/` вместе с лицензией MIT.

```sh
npm start
```

Откройте `http://localhost:3000`. Для планшета в той же сети используйте IP компьютера и порт 3000. Можно разместить содержимое репозитория на обычном статическом хостинге или включить GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**. Не открывайте `index.html` через `file://`: игре нужен HTTP-сервер для ES-модулей.

## Деплой на Vercel

В репозитории есть `vercel.json`: пресет **Other** (`framework: null`), команда сборки `node scripts/build.mjs`, каталог публикации `dist`. Сборка копирует HTML, CSS, игровые модули и локальный Three.js. Локальный Node-сервер находится в `scripts/serve.mjs` и в публикацию не включается.

При подключённой интеграции GitHub коммиты в `main` запускают новый деплой. Root Directory проекта должен указывать на корень репозитория. Отдельные команды установки зависимостей и запуска сервера для Vercel не нужны.

Если старый деплой возвращал `404 Not found`, дождитесь нового деплоя с этим конфигом. При ручной публикации выполните `npm run build` и публикуйте содержимое `dist`.

## Первый рабочий день

1. Проснитесь на втором этаже своего дома. Лестница находится справа, вдоль боковой стены; верх лестницы — у задней стены.
2. Спуститесь и оденьтесь у гардероба возле входа. Чтобы взаимодействовать, посмотрите на предмет и подойдите ближе.
3. Откройте входную дверь, выйдите и сядьте в машину перед домом.
4. Откройте навигатор и примите заказ. На карте можно выбирать здания и прокладывать маршрут.
5. Доедьте до заведения, остановитесь и выйдите. Откройте дверь, подойдите к стойке и заберите заказ.
6. У задней части машины откройте багажник, затем погрузите коробку отдельным действием.
7. Доедьте до адреса, припаркуйтесь во дворе в пределах 26 метров от дома и достаньте заказ из багажника.
8. Позвоните в звонок справа от двери. Через 5–10 секунд дверь откроется, клиент выйдет. Подойдите к нему и отдайте заказ.
9. Получите оплату и чаевые. Принимайте новые заказы, пока не заработаете $100 (обычно четыре доставки).
10. Верните машину домой, зайдите в спальню и ложитесь спать. Можно начать следующий день.

Дома можно открывать шкафы и холодильник, а затем есть из открытого холодильника. Сытость постепенно уменьшается; на низком уровне персонаж ходит медленнее.

## Управление

| Действие | Компьютер | Планшет |
| --- | --- | --- |
| Ходить / ехать | WASD или стрелки | Левый джойстик |
| Смотреть | Мышь; при недоступном захвате — зажать левую кнопку | Провести пальцем по правой части экрана |
| Взаимодействовать | E | «Действие» |
| Карта | M | «Карта» |
| Выйти из машины | F, после остановки | «Выйти» |
| Бег | Shift | — |
| Пауза | Esc или кнопка Ⅱ | Кнопка Ⅱ |

Нужен браузер с WebGL 2 и ES-модулями/import maps. Предусмотрены режимы графики для планшетов. Ограничений запуска по размеру экрана нет: игра открывается на компьютерах, планшетах и телефонах. Интерфейс рассчитан на компьютеры и планшеты; на телефоне играть может быть неудобно. Рекомендуется горизонтальная ориентация планшета.

## Что реализовано

- Город размером около 400 × 400 игровых метров, 25 зданий: 21 жилой дом и 4 заведения.
- Свой двухэтажный дом с проходимой лестницей, кроватью, кухней, мебелью и гардеробом; гараж с открывающимися воротами.
- Интерьеры всех жилых домов; пекарня, пиццерия, продуктовый магазин и кофейня с разными стойками, товарами, столиками и сотрудниками.
- 18 гуляющих пешеходов в зимней одежде, часть заходит в заведения; 8 машин на дорожных маршрутах.
- Ходьба и вождение от первого лица, кабина, поворот руля, скорость, столкновения со стенами, оградами и дорожными машинами.
- Кликабельная карта, мини-карта и маршрут до заведения, клиента или выбранного здания.
- Полный цикл заказа, коробка в руках, багажник, звонок, выход клиента, оплата и чаевые.
- Снег, звёзды, тёплые окна, фонари, звук звонка и двигателя.
- Пауза, заработок за день, возвращение домой, сон и следующие дни.
- Автосохранение в localStorage этого браузера каждые 5 секунд и после ключевых действий. Облачного сохранения и мультиплеера нет.

## Проверка и границы версии

```sh
npm run check
npm test
```

Автоматические проверки покрывают последовательность доставки, достижение $100, адреса, маршруты, сохранения, сборку 3D-сцены, проходимость открытых входов и локальные ресурсы. Визуальное прохождение в браузере и проверка на физическом планшете пока не проводились.

Город стилизованный, с процедурными моделями. Пешеходы и транспорт движутся по заданным маршрутам; это базовая симуляция, без полноценного дорожного ИИ и сложных расписаний жителей. Маршруты навигатора следуют сетке улиц, но не учитывают временные помехи. Магазины обслуживают доставку, отдельной системы розничных покупок нет. Сохранение содержит состояние персонажа, машины и заказов; открытость шкафов и положение прохожих сбрасываются после перезагрузки. Освещение сохраняет зимний вечерний стиль в течение всей смены.

## Структура

- `src/game.js` — игровой цикл, движение, взаимодействия, интерфейс, звук, карта и сохранения.
- `src/world.js` — геометрия, интерьеры, двери, NPC, транспорт и снег. Статическая геометрия объединяется по материалам для уменьшения количества отрисовок.
- `src/rules.js` — независимые правила заказов, маршруты и проверка сохранений.
- `tests/` — тесты на встроенном тестовом движке Node.js.
- `vendor/` — локальная копия Three.js и утилиты объединения геометрии, лицензия Three.js.

Изображения референсов не распространяются в репозитории. Все игровые модели создаются кодом; внешние CDN, аккаунты и API для запуска не нужны.
